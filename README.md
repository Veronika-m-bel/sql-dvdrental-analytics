# 📊 SQL Analytics & Data Quality Portfolio (`dvdrental`)

## 📌 О проекте
Этот репозиторий содержит коллекцию аналитических SQL-запросов и скриптов для валидации данных, написанных для учебной базы данных **`dvdrental` (PostgreSQL)**.

Цель проекта - продемонстрировать практические навыки в следующих областях:
* **QA & Support (Проверка целостности данных):** поиск «потерянных» транзакций, аномалий и нарушений связей между таблицами.
* **Бизнес-аналитика (BI):** расчет ключевых метрик (выручка магазинов, средний чек, динамика продаж по месяцам).
* **Продвинутый SQL:** использование общих табличных выражений (`CTE`), многоуровневых подзапросов и сложных многотабличных соединений (`JOIN`).

---

## 🛠️ Стек технологий
* **СУБД:** PostgreSQL
* **База данных:** `dvdrental` (классический симулятор проката видеофильмов)

## 🚀 Основные разделы и бизнес-кейсы

### 1. Поиск аномалий и проверка целостности данных (QA / L2 Support)
* **Поиск аренд без оплат:** Выявление «осиротевших» записей в определенном диапазоне с помощью `LEFT JOIN` и `IS NULL`.
* **Поиск городов без магазинов:** Исключение ложных срабатываний при связях «один ко многим» с использованием подзапросов (`NOT IN`).

### 2. Бизнес-аналитика и отчетность по продажам
* **Рейтинг магазинов и сотрудников:** Расчет выручки с детализацией по физическим адресам точек продаж (соединение 4-х таблиц).
* **Помесячная динамика продаж:** Агрегация финансовых данных с форматированием дат (`TO_CHAR`).
* **Анализ среднего чека:** Расчет среднего значения по платежам за 2006 год с округлением (`ROUND`, `AVG`).

### 3. Продвинутая аналитика и сегментация (CTE)
* **Сегментация клиентской базы:** Поиск покупателей, у которых количество аренд строго ниже среднего значения по всей базе, с использованием **CTE (`WITH`)**.

## 🛠️ Как запустить проект локально

1. Скачайте и установите тестовую базу данных  [**PostgreSQL `dvdrental`**](https://www.postgresqltutorial.com/postgresql-getting-started/postgresql-sample-database/).
2. Разверните базу в PostgreSQL через `pg_restore` или визуальный клиент (DBeaver / pgAdmin).
3. Откройте файл `dvdrental_analytics.sql` в вашем SQL-клиенте и выполняйте запросы.
